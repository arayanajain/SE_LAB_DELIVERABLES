# Software Engineering Lab Deliverables

This repository contains my Software Engineering Laboratory submissions. Each lab focuses on a different stage of software development, including requirements analysis, project planning, software architecture, application development, static code analysis and software testing.

## Lab Submissions

| Lab | Topic | Project / Description |
|---|---|---|
| [LAB 1](<LAB 1/>) | Requirements Engineering | Requirements and use cases for a Hospital Bed and ICU Allocation Dashboard. |
| [LAB 2](<LAB 2/>) | Agile Development | Sprint planning using Jira, including epics, user stories and backlog organisation. |
| [LAB 3](<LAB 3/>) | Software Architecture | Microservices-based architecture for a Hospital Bed and ICU Allocation Dashboard. |
| [LAB 4](<LAB 4/>) | Application Development | Vibe coding exercise involving the development of a Mastermind game. |
| [LAB 5](https://github.com/arayanajain/L5_16_pet_shelter) | Static Code Analysis | Analysis and improvement of an Animal Shelter Adoption Register using Pylint, Bandit and Flake8. |
| [LAB 6](https://github.com/arayanajain/L6_L7_16_student_grades/tree/main/Lab%206) | Code and Branch Coverage | Testing a Student Grades program using pytest and coverage tools. |
| [LAB 7](https://github.com/arayanajain/L6_L7_16_student_grades/tree/main/Lab%207) | Fuzz Testing | Testing input-handling functions in the Student Grades program using Hypothesis. |

## Tools and Technologies

- **Project Planning:** Jira
- **Programming Language:** Python
- **Static Analysis:** Pylint, Bandit, Flake8
- **Testing:** pytest, Coverage.py, Hypothesis
- **Database:** SQLite
- **Architecture:** Microservices
